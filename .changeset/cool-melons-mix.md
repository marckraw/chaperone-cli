Native rules for what Backbase's preset needed command rules for, and per-result baselines for the command rules that remain: `registered-in-map` reads an `exceptionsFile` (a JSON object mapping schema names to the reason they are not in the map; listed names pass), `file-contract` (`captureFromPath.transform`) and `file-pairing` (`pair.transform`) convert captures to pascal, camel, kebab or snake case, so a folder check can require `fan-stack.sb.ts` to sit in `FanStack/`, and a command rule with `"output": "results"` prints a JSON result list (`file`, `message`, optional `fingerprint`, `line`, `column`, `suggestion`) whose results `check` and `baseline` treat like native violations, so baselining one no longer hides the next. A result list the command cannot produce is a rule-level error, which keeps the rule's baseline entries unverified. `file-pairing` now treats a file that `pair.from` matches as transformed even when `pair.to` maps it to itself (it used to report "Could not transform"), so a file can be its own companion.
